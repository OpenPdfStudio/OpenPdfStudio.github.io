# OpenPdfStudio website

Source for [openpdfstudio.github.io](https://openpdfstudio.github.io/), the website for [OpenPdfStudio](https://github.com/younisiqbal/OpenPdfStudio).

It is a plain HTML and CSS site with no build step. GitHub Pages serves it from the root of the `main` branch.

Download links point to the latest release of the app repository, so new releases show up on the site without changes here.
